# 暮野诸国 / Dusk Realms

**1.35.0「舰影与苍穹」**：建设城镇、指派村民、发展八个种族的文明，指挥陆海空部队与 NPC 争夺领土。

[下载 Windows x64 免安装 EXE](https://github.com/nnyy-yn/dusk-realms/releases/download/v1.35.0/DuskRealms-1.35.0-Windows-x64.exe) · [本版更新说明](https://github.com/nnyy-yn/dusk-realms/releases/tag/v1.35.0)

下载后直接运行，无需安装 Node.js 或服务器。单人支持离线游玩，P2P 联机需要网络。更新前保存并关闭旧版，再运行新版 EXE；继续使用原存档目录。游戏内「检查更新」可下载新版并验证大小与 SHA-256。

准备界面可设置种族、阵营颜色、出生点、NPC 难度、四季和人口上限。市中心招募村民，对应军事设施训练兵种；选中生产建筑后右键设置集合点。房屋增加人口容量。

按 N 打开侧边建造目录，Esc 收起，F1 显隐提示，F11 切换全屏。普通人物及海空岗位的第一人称用于观察，己方国王或领主可直接控制。

新版重做舰船、航空和攻城机械的结构与材质，加入实际战斗驱动的机械动作、炮口特效和海面尾迹，改进 NPC 登陆评估、人物握持和建筑施工。美术仍在迭代，尚未达到 AAA 水准。

验证：205 项定向回归、78 项海空检查、65 项实际包离线界面检查；非全套回归。本轮未启动原生 EXE，公网 P2P 与原生窗口模式未复测。
