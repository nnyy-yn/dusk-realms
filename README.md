## 操作与入口

- F2或右侧「发展」查看本国收支、住房、时代建议和建筑升级。展开「单位生产」查看订单，并集中暂停或继续本国生产。
- 选中生产建筑，可一次排产1–5批，右键可达地面设置集合点，也可清除集合点让后续单位在建筑附近待命。
- N打开侧边建设目录；右侧「军队」「外交」「功能」分别归类，按 / 搜索功能。Esc收起面板，F1显隐提示。
- WASD平移、Q/E旋转视角，选军后相同。军队右键移动、F攻击移动、X驻守、U埋伏、P巡逻，Shift+右键添加途经点。
- 军队头顶名称默认隐藏，点击后在右侧查看详情；「功能 → 系统 → 界面与画质」可开启名称。
- 普通人物和海空岗位的第一人称用于观察；只有本国国王或领主可直接操控。

本版完善生产管理与装备细节，包含批量排产、清除集合点、集中暂停续产、可选军队名称、曲面盾牌、箭镞箭羽与回折盔缘。
