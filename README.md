## 开始游玩

下载 EXE 后直接运行，无需安装 Node.js 或服务器。单人可离线游玩，P2P 联机需要网络。更新前保存并关闭旧版，再运行新版，继续使用原存档目录。

准备界面可设置种族、时代、季节、种子、地图规模、国家数量和每国人口上限，并逐国设置种族、阵营颜色、出生点和 NPC 难度。人口增长仍需空余住房。市中心招募村民，兵营、射手营、马厩生产对应兵种，右键设置生产集合点。

## 战后救治安排

按 G 打开全军，在「战后医护 → 救治安排」中暂停或继续本国伤兵救治。无伤兵时也能提前设定。暂停保留医护岗位和公共卫生作用，只停止伤兵康复及对应的救治支出；日常口粮照常消耗。继续后仍需完好且有工人的医馆、粮金和驻军名额，每康复1人沿用2粮、1金的原价格。该设置随存档保存，旧存档默认自动救治。

## 自动维修建材预算

选中工匠工坊，展开「专属功能与产出详情 → 自动维修建材保留」，分别填写木材、石料最低库存，再应用到全国。所有本国工坊共用这份保留量，仅用超出的建材自动维修；补货后满足条件会继续。可以先于战损设定，0表示该项不限，两项都为0恢复原规则。此设置随存档保存，不改变工人、维修费用与目标顺序；手动修复、升级、生产仍按原规则支付。单位自动生产的库存保护继续在各生产建筑单独设置。

## 经济设施补岗

按F2打开发展总览，展开「经济设施补岗」，选择粮食、木材或石料生产。使用当前空闲村民，先向未派工设施分散安排第一人，再轮流补齐空岗位；人数不足只安排可用部分。粮食包含农庄、磨坊、牧场和渔港，木材对应伐木工坊，石料对应采石场。不抽调已有工人或总部建造者，不招募人口，不改变资源、训练订单或升级；村民仍需沿原路线到岗。完成后收起总览即可恢复清爽视野。

## 操作与功能入口

- 战略视角：WASD 平移、Q/E 旋转，选中军队后也相同。滚轮缩放，右键拖动视角。
- 军队：右键移动，F 攻击移动、X 驻守、U 埋伏、P 巡逻；Shift+右键添加途经点，Ctrl+1–5 编组。
- F2 打开本国发展总览，查看收支、住房、建议和本国建筑升级；N 打开建设目录。
- 右侧固定发展、建设、军队、外交、功能五个文字入口。按 / 打开五类功能导航，输入关键词可跨类搜索。Esc 收起，F1 显隐按键提示。
- 功能 → 系统可打开教程、画质与UI缩放、AI托管、存档和音乐；按钮悬浮显示说明与快捷键。
- 普通人物和海空岗位的第一人称仅用于观察；只有自己的国王/领主可用WASD移动、E释放技能、左键战斗。

## 军队名称显示

军队头顶名称默认关闭。单击本国部队即可在右侧军队详情查看编号、兵种、人数、国家、种族、时代和阵营；多选时可展开名单。需要头顶名称时，进入「功能 → 系统 → 界面与画质」，开启「军队头顶名称」。设置即时生效并保存在本机，恢复界面默认会再次关闭；关闭不影响军令、悬浮兵力条或迷雾规则。

## 集合点与就地待命

选中本国市中心、兵营、射手营或马厩，右键可达地面或点击「设置集合点」，让后续出生单位前往指定地点。已设置时，旁边出现「清除集合点」；清除后，新单位恢复在生产建筑附近待命，已经出发的单位继续原路线。清除不退款、不重置队列，不改变暂停、循环或库存保护设置；结果随存档保存。按钮仅在所选建筑详情出现。

需要集中新兵时，先为一座兵营、射手营或马厩设置集合点，再展开该建筑的「管理订单」，点击「应用到全部陆军军营」。本国现有三类军营会共用这一目标；任一军营损毁或无法抵达时，整批保留原设置。市中心、现役部队和之后新建的军营保持各自设置。

## 取消建筑升级

在F2「发展总览 → 施工中」或所选建筑的升级区，展开「工程管理」，可查看预计返还材料并取消升级。主机按点击时的剩余工期比例计算，逐种资源向下取整并受库存上限限制；已施工部分不返还。取消后保留当前等级和耐久，工人、付费生产订单与集合点保持原安排。重新升级须重新付原价并经历完整工期；AI托管之后仍可能重新安排工程。

## 本国单位生产总览

按 F2 展开「单位生产」，可在每座设施的行内直接按原价排产1批，或独立暂停/继续；同一行显示人数、费用、工期、进度和不可用原因。暂停一座不会暂停其他设施。付费订单、循环计划和工人保留；需要派工、批量计划或集合点时，点击该行的定位箭头进入建筑详情。

按F2或点击「发展」，展开「单位生产」，集中查看本国市中心、兵营、射手营和马厩的订单、当前剩余及暂停/缺工/库存保护等原因。每行箭头直接进入对应建筑，再调整招募、暂停、库存保留量或派工。原建筑升级筛选保持独立。

待产的兵营、射手营或马厩缺工时，同一区域显示「为待产军营补工」。仅从空闲村民中各派1人，优先已付订单，再考虑当前可续单的循环计划；人数不足时按固定顺序分配。不会从其他设施调人，不占用总部施工者，也不改变暂停状态、订单进度、资源或集合点。

同一区域新增「全部暂停 / 全部继续」，只调整本国当时已有的四类生产设施。已付订单和剩余时间、有限计划、库存保护、集合点、工人及资源保留；继续后仍需满足原有生产条件。后建的设施沿用自己的生产状态，其他国家不受影响。按钮随「单位生产」折叠，暂停结果随存档保存。

## 一次排产多批

选中本国市中心或军事生产设施，在招募区选择「每次排产」1–5批，再点击招募按钮。村民每批1人，士兵每批3人，按钮显示本次总人数和总费用；主机检查整批资源、住房、兵力与队列空位，条件不足时整批不扣费、不入队。队列最多5单，每单仍按原工期逐一生产，追加不会重置已训练的订单。默认1批；取消订单按实际已付费用退款。

## 自动生产库存保护

在生产建筑中展开「自动生产保留资源」，填写粮木石金的最低库存并保存。自动下单扣费后仍须保有这些数量，库存不足时等待；0表示该项不限。已付款订单继续完成，手动下单沿用原规则，AI托管自动下单遵守保留量。每座建筑单独设置，随存档保存。

## 管理生产订单

在本国生产建筑的详情中展开「管理订单」，一次取消全部待产订单，并停止循环计划。退款按实际已付费用和库存上限计算，界面显示可到账资源；已出生单位不退款，暂停状态与集合点保留。AI托管之后仍可能重新下单，持续停产请先暂停生产。

## 暂停单位生产

选中本国市中心、兵营、射手营或马厩，在生产标题旁点击「暂停生产」。已付订单、剩余时间和循环配额保持不变，其他设施与升级施工继续运行；点击「继续生产」后从原进度接着完成。暂停不会撤回工人，需要调岗时在原派工区操作。状态随存档保存，AI托管尊重此安排。

## 步弓协同布防

同时选中一队本国步兵和一队弓兵，在「布防朝向」选择自动或地图北、东、南、西，点击「布置步弓掩护」，再点击弓兵防守位置。自动按两队前往目标的方向布置；指定方向则让步兵在那一侧靠前一格，需要两个不同、已探索且陆路可达的位置。指定侧被水域、陡坡或本国占位阻断时整批不执行；不会改成其他朝向。

部队真实行军，到位后各自驻守，途中可重新下令或存档；原地将朝向由东改为西时，步兵也要实际走到另一侧。朝向选择只保留在本次本地选择中，换选或重载回到自动，已布置的真实位置保留。途中用Shift+右键追加移动时，取消到位驻守安排，继续完成当前路段后按途经点行军。

选军后在战术页展开「协同防御」查看附近本国配合部队。原有步兵掩护仅承担正面箭路中的部分损失，不保证抵挡侧面或背后的来箭；驻守迎骑仅在步兵实际到位后生效。选军和布防不会占用WASD/QE视角按键。

## 步兵驻守迎骑

专门步兵抵达目的地后按X驻守、且没有后续途经点时，受到敌方骑兵的近战伤害减少25%。原军队详情显示就绪状态，悬浮查看具体条件。移动、攻击移动、巡逻、伏击、返营和未到位均不生效；旧制混编不享有。它不增加反击伤害，不减免其他近战、箭雨、城防、领主或灾害伤害。伤兵仍按实际损失计算，原残兵阈值继续适用。

## 箭塔协防

让至少3名本国专门弓兵实际走到有在岗工人的本国箭塔1.5格内，按X驻守。山脊未阻断时，最近一座箭塔获得20%攻击伤害；一队只提名一塔，每塔只取最近一队，不叠加，落选队不会转派次近塔。移动、途经点、返营、减员不足3人、撤岗或损毁立即取消支援；原射程、射速、隐蔽与停战规则保持。选军后打开「战术 → 协同防御」，或选中塔楼展开专属详情，查看真实状态。

## 优先集火

选军后展开「优先集火」，选择全队都能攻击的可见敌军。指令只调整交战优先级，不增加伤害或重置冷却，不改路线；超射程、被山脊遮挡、隐蔽或消失时恢复自动交战。近战保留原双方冷却。

## 工坊优先维修

选中受损本国建筑，展开「专属功能与产出详情」，设置或取消优先维修。每国一个目标；4格内已派工工坊先修该目标，费用和速度不变。缺人、缺料时保留安排，修满、拆除或易主后清理。取消恢复原大厅、箭塔和编号顺序。

## 时代与识别

正常新局需要完成当前时代的特色设施，再满足人口、科技和资源条件，才能启动晋升。原始需礼拜堂，中古需工匠工坊，工业需航空场，现代需3级王庭，各族使用自己的特色名称。时代工程完成后，建造目录才开放对应新设施；NPC遵守相同建造与升级规则。旧存档保留原时代规则。

当前可见的敌军显示步兵、弓兵、骑兵及攻城编队；悬浮可见国家、种族、时代和阵营。战争迷雾和埋伏不会泄露未发现部队。

## 新兵军令与城防整备

选中本国已设置集合点的兵营、射手营或马厩，展开「管理订单」，选择「移动集结 / 驻守集结」。仅影响之后出生的新兵，包括已付待产订单；现役军队不变。驻守行军途中可按原规则交战，实际到位后才可协防。

按F2打开「发展总览 → 需修复」，点击「仅修城防」，按原价和阵营折扣修复本国大厅、箭塔和城墙。资源不足只处理可负担部分；经济建筑、迁移总部、岗位、等级与已付工作不变。只有经济建筑受损时，此按钮隐藏。
