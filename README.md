# 暮野诸国 · Dusk Realms

一款 3D 中世纪村庄经营与战争游戏。建造城镇、分配村民、发展科技，用外交或远征决定诸国的未来。

## 下载就能玩

**[前往最新版本，下载免安装 Windows EXE](https://github.com/nnyy-yn/dusk-realms/releases/latest)**

在 Release 的 **Assets（资源）** 中下载 `暮野诸国-版本号-Windows-x64.exe`，双击即可游玩。无需安装 Node.js 或另外搭建服务器。适用于 Windows 10/11 64 位和支持 WebGL 2 的显卡。首次打开会在临时目录解压运行环境。

单人模式可以离线游玩；与朋友联机需要网络。首次发布版为 **v1.2.0「使节与学者」**。

## 玩法

- 12 类设施：村舍、农庄、工坊、采石场、集市、兵营、箭塔、城墙、花园、风车与礼拜堂等。
- 安排村民生产粮食、木材、石料与金币，训练军队，修复和升级设施。
- 四个阵营，三个难度；无人控制的国家由 NPC 建造、发展并发动远征。
- 恶龙、龙卷风、丰收、商旅和疫病等随机事件。
- 农业、防御、后勤三条科技路线，每条三级；停战协议和资源援助。
- 最多 4 人 P2P 联机，各经营一个国家；NPC 补齐空缺并接管断线国家。
- 统一到一个阵营后，可继续建设或开始下一局。

## 操作

左键选择或建造，右键拖动、WASD 平移，滚轮缩放，Q/E 旋转。按住 Shift 连续建造，Home 归城，空格暂停，M 打开诸国，R 打开学府与维护，H 查看指南，Esc 返回。F11 切换全屏。

## 存档与更新

进度自动保存在 `%APPDATA%\DuskRealms`，也可以在菜单导出、导入 JSON 存档。新版免安装 EXE 会沿用原来的存档目录。

主界面或游戏菜单的 **检查更新** 会查询本仓库的正式 Release。发现新版后可下载并通过 SHA-256 校验；点击 **打开下载位置**，保存进度、关闭旧游戏，再双击新版。旧 EXE 和存档均保留。

当前正式版不会提示更新到自身；发布更高版本后，已有玩家即可从游戏内检查并下载。

## P2P 联机

房主创建房间，把 `dusk-…` 房间码发给朋友，选择国家后开始。双方请使用同一版本。默认公共信令帮助建立 WebRTC 连接；某些网络无法直连时，需要在高级设置填写可用的 TURN 中继。

房主负责模拟世界和校验指令，只有房主能暂停或调整速度。房主离开会结束当前连接；玩家可从已收到的快照转为单人继续。目前没有自动主机迁移。
