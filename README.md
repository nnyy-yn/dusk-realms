## 操作与入口

- F2或右侧「发展」查看本国收支、住房、时代建议、建筑升级；展开「单位生产」查看实际订单、剩余时间和暂停或缺工原因，点击箭头进入对应建筑。
- N打开侧边建设目录；右侧「军队」「外交」「功能」分别归类，按 / 可搜索功能。Esc收起面板，F1显隐提示。
- WASD平移、Q/E旋转视角，选军后相同。军队右键移动、F攻击移动、X驻守、U埋伏、P巡逻，Shift+右键添加途经点。
- 普通人物和海空岗位的第一人称用于观察；只有本国国王或领主可直接操控。
