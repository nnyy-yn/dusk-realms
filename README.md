## 本版更新

- 准备界面的第一页直接编辑本局国家：每国独立种族、阵营颜色、出生点和 NPC 难度。15 国名单独立滚动，已占出生点会交换，同色为盟友。

## 开始游玩

市中心招募村民，兵营、射手营、马厩等训练对应兵种。选中生产建筑后右键设定集合点，新单位会前往该地点。房屋提供人口容量，人口总上限在准备界面设置。

WASD 平移地图，右键拖动或滚轮缩放，Q/E 旋转。按 / 打开可搜索的领地中枢，N 打开建造，F1 显隐提示，F11 切换全屏。按钮悬浮时可查看说明与快捷键。

普通村民、士兵及海空岗位的第一人称用于观察；只有己方国王或领主可直接移动、战斗和释放技能。领主需要在本族王庭召唤。
