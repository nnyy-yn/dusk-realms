# 暮野诸国 · Dusk Realms

一款 3D 跨时代经营与战争游戏。从村庄开始，修建设施、安排村民、发展科技，让自己的文明走向未来，再用外交、陆军、海军与空军决定诸国的命运。

**当前版本：v1.15.0「海空战场」。**

## 下载就能玩

**[前往最新版本，下载免安装 Windows EXE](https://github.com/nnyy-yn/dusk-realms/releases/latest)**

在 v1.15.0 的 **Assets（资源）** 中下载 **DuskRealms-1.15.0-Windows-x64.exe**，双击即可游玩。适用于 Windows 10/11 64 位和支持 WebGL 2 的显卡，无需安装 Node.js、浏览器扩展或本地服务器。首次打开会在临时目录解压运行环境。

三个发布附件中，**玩游戏只需要 EXE**：SHA256SUMS.txt 用于校验，update.json 供游戏内更新使用。GitHub 自动附带的 Source code 压缩包不是游戏程序。单人可以离线游玩，与朋友联机需要网络。

## 这次能玩什么

- **16 个阵营、6 种族群**，旗帜与种族独立选择。人类、精灵、矮人、兽人、半身人与地精都有特长和时代造型。
- **原始、中古、工业、现代、未来**五个时代，可选择起始时代并逐步进阶；NPC 有三档难度。
- **6 档地图、2–12 个国家**，实际国家数可在地图容量内自由选择；每国人口上限可设为 **12–1000**，居民仍需要住房与粮食。
- **大陆诸国、群岛争霸、高原裂谷**三种战场，可开关战争迷雾；单人对抗 NPC，或最多 12 人各经营一国，空缺和离线国家由 NPC 接管。
- **19 类设施（含领主大厅）**，涵盖农庄、牧场、渔港、集市、工匠工坊、医馆、兵营、造船坞与航空场；建造、升级、派工和自动维修共同维持城镇。
- 经营四季粮食、商队贸易和港口接驳，发展三条科技路线；提出停战、援助资源，救治战后伤兵。
- 陆军有标准、疾行、攻城三种军阵，可途中召回；海军运兵沿水路登陆，工业起的空军可以越障突袭，但不能独自占国。
- 恶龙、龙卷风等随机事件，五时代与六族模型，以及可旋转、缩放的 **13 类三维模型图鉴**。
- 保留原创内置配乐，也可添加自己的本地音乐，调节音量、切换曲目与自动播放下一首。最多 20 首、单首 40 MiB、合计 200 MiB；本地曲目会保存，音乐文件不上传或发送给其他玩家。
- 地图上只剩一种阵营时，可以继续经营，也可以开启下一局。

## 操作

左键选择或建造，右键拖动、WASD 平移，滚轮缩放，Q/E 旋转。按住 Shift 连续建造，Home 归城，O 显示全图，空格暂停；顶栏切换 1× / 2× / 4×。

M 打开诸国，G 管理军队与海空军，B 查看设施，T 查看商路，R 进入研究，C 查看民政账本，V 查看时代，H 查看指南，Esc 返回。F11 切换全屏。

## 存档与更新

存档自动保存在 `%APPDATA%\DuskRealms`，菜单也可导出、导入 JSON。建议升级前先导出备份；新版 EXE 会沿用原存档目录，旧世界可作为单人继续。

主界面或游戏菜单的 **检查更新** 会查询本仓库正式 Release。发现新版后可下载并验证 SHA-256；点击 **打开下载位置**，保存进度、关闭旧游戏，再双击新版。程序保留旧 EXE 和存档，不自动替换或启动新版。

自己添加的音乐保存在本机，独立于世界存档；列表、选择和音量重开保留，删除曲目会移除其本地副本。

## 与朋友联机

房主设置世界并创建房间，把 `dusk-…` 房间码发给朋友。玩家选择空席，也可在开局前选择自己的种族；空缺国家由 NPC 补齐。所有人须使用 **1.15.0**，旧版客户端会被拒绝。

默认公共信令帮助建立 WebRTC 连接；受 NAT 或网络限制时可能需要在高级设置配置可用的 TURN 中继。并非所有公网网络都能直接互连。

房主模拟世界并校验指令，只有房主能暂停或调整速度。客方断线后 NPC 接管，开局后原浏览器标签可用原身份重连。房主离开会结束当前连接；玩家可将收到的快照转为单人继续，目前没有主机迁移、公共匹配大厅或云存档。
