简单 NPC 从第 16 天起缓慢出征并保留更多驻军；标准和困难从第 13 天起扩张，分别最多同时派出两支、三支远征军。困难能更快回防、评估城防并召回受损军队；攻城需要真实集结兵力、选择阵型并维护自己的城防。

点击侧边王冠打开「国王与领主」。在军事分类建设王庭，安排至少一名村民担任侍从，再付费召唤本族领主；每国只能有一位存活领主，死亡后需重新召唤。点击「进入第一人称」后用 WASD 移动、右键拖动看向、左键攻击准星附近射程内的可见敌军、E 释放特色技能，Esc 返回战略视角。点击「人物视角」或已选村民/士兵面板的观察按钮，可跟随当前可见人物，观察模式无法直接操控他们。单人暂停、菜单、目标离场和战争迷雾均会限制相关输入。

大陆和高原的 10–15 国开局采用种子确定的自然分散出生点，保留各国 6 格发展区、林石资源与可达的近岸湖泊。宽阔平原和丘陵之间分布弯曲山系、台地、河谷与湖区；河流接入外海，少量浅滩供陆军涉水，保持舰船水路连续；山脊阻挡行走、直接射击、建设与地形破坏，陆军需沿实际可通行陆路绕行。火山是局部山体中的真实凹坑、厚实口沿与低处熔池，熔流沿实际坡面下降。群岛继续隔海发展，不用山脊把海面连接起来；旧档沿用保存的原尺寸、方形或圆形边界及地形，不重新生成。镜头限位、真实地面、战争迷雾和规则共用同一条不规则轮廓，未知区不再堆叠黑色地格墙。

海空行动的军令卡提供「舰桥视角」「驾驶舱视角」，也可从人物视角中的海空分类进入。每架飞行载具可在驾驶位、机首射击位、尾部射击位之间直接切换；三个位点分别使用真实机舱坐标、朝向与独立内部几何，尾部视角朝后。飞艇、多座攻击机和未来载具各有对应的外部驾驶舱、射击舱和炮塔；舱内有实体窗框、仪表、炮架和瞄具。内饰跟随机身，转头时不会跟着视线转动，自己不透明的外壳只在舱内观察期间隐藏，退出恢复。镜头平滑转向、保持水平，不使用步行晃动；暂停时可继续转头查看，F 或「回正航向」返回当前舱位正前方，Esc 恢复原战略取景。海空与射击位均为观察模式，WASD、左键和 E 不发出单位移动、开火或技能指令。返航继续随行，离场或失去当前视野时退出。

外海加入随时间起伏、贴岸减弱的多尺度涌浪、深浅水色和零散碎泡，沿岸散布礁石与碎石，外围有少量不可进入的海蚀岩山。草地、泥土、岩层和湿岸采用四类原创地表图层；建筑增加连续尺度的砌石、屋面与檐下明暗，仍保留六族、五时代的区别。

火山有独立的种子活动周期和喷发概率，活动增强时预警。自然大图（含保存的 120/144 格旧世界）喷发瞬间波及 12 格，历史小尺寸世界仍为 4 格；范围内的领主、野战陆军、野外单位和建筑会受到伤害；附近设施受灾还会消耗粮食、降低士气。伤害按次结算，不直接减少村民人口，余焰与烟尘不会重复扣血。初始至少 120 秒不喷发。熔岩与火山地块不能通行或建造。

点击侧边「野外与灾害」巡查当前可见的荒野部族、荒野巨兽与流散士兵。野人和怪兽会在营地附近主动袭击，己方军队或领主可以迎战；流散士兵保持中立，己方陆军或领主接近 3 格且短程陆路可达时，可按每人 6 金币整队招降加入驻军。兵力容量或金币不足会拒绝整次招降。野外单位、火山活动和所有伤害都随正常存档、房主快照保存，迷雾隐藏当前不可见的群体；旧档不会突然生成这些新实体。

新旅程分为「世界设置 → 文明与旗帜 → 选择出生点」。在根据种子生成的实际地形图上点击安全区域编号，选择具有相同初始设施与建设保护区的起点；出生点选择不改变本局国家数或地形种子。联机房间可展开出生位置图，选择空缺国家即选择对应起点，每国仍最多一名玩家，空缺国家由 NPC 发展。

选择己方主大厅后，可以「迁移总部」：基地打包 4 秒，沿已探索的空草地行军，再展开 6 秒；每格移动 1.5 秒，花费粮食、木材、金币各 20。打包、行军与展开期间，大厅住房与被动城防暂停，不能升级、手动修复、批量修复或由工坊维修，仍可遭受攻击。已有设施保留原址；途中中止会停在最近已到达的地块，不退还费用。

也可在大厅点击「派村民重建」，或选中一名空闲村民后点击「由这名村民重建总部」。选定安全新址后，所指定的村民沿陆路前往，每格行走 1.2 秒，再施工 18 秒；未指定时使用编号最低的空闲村民。工程消耗木材 80、石料 60、金币 40，并占用这名真实村民，期间无法另行派工。完工前旧总部照常提供住房与城防，也照常承受伤害和接受维修；完工迁移同一个大厅，保留等级与当时生命值，不额外回血或复制大厅。

两类工程每次最多离原址 10 格，需要已探索的安全空草地与可达陆路，并预留施工位置或基地通道。道路受阻、工程村民死亡或总部被毁会中止工程并释放预留人手，已消耗资源不退还；即使攻击者全部战死、国家尚未被占领，零生命总部的工程也会停止。总部被攻陷仍按原规则处理国家归属，工程不会提供免死保护。

总部工程阶段、指定村民、补员后的真实兵力与资源、在途军队路线都会随存档及房主快照保存。搬迁不会拖动已出发的军队；部队抵达旧总部位置后，需沿可通行陆路继续前往新址，道路不通则停驻。1.25 本地版继续读取旧世界；联机双方须同为 **1.25.0**，使用原身份令牌重连可恢复本国进度。

选择一支野战陆军，展开「兵营补员」，输入目标总兵力。部队须在有工人的己方兵营 3 格内驻守，且 4 步内陆路可达，周边 4 格内不能有敌军或敌方设施；每调入一名现役驻军，花费粮食与金币各 1，军团容量随兵营工人数提高。伤兵不能直接补入，行军、返程、战斗、冷却或有后续军令时不能补员，海空部队也不能使用；不会额外生成人口。战损可为小数，只调入整数新兵，例如 6.4 人补到目标 12，实际调入 5 人，结果为 11.4 人；驻军或资源不足时拒绝整次补员，不部分扣款。

攻城部队进入射程便停下，每两秒攻击一座当前可见、山脊无遮挡的入口城墙或邻近箭塔；破除局部防线后攻击大厅。每次最多造成该建筑最大生命15%的结构伤害，远处或背面的城墙不提供全境无敌，也不会一起受伤。箭塔与大厅按各自真实射程还击，驻军仅在大厅交锋时伤亡；攻城器械击毁建筑才产生一次地形破坏。部队可保持在战场，军令面板显示阶段及可见目标生命，随时召回沿路归营；幸存士兵只在抵达总部后归队，存档和联机快照保留战况。标准与突袭军阵仍按一次远征突击结算。

## 玩法

1. 在主菜单点击「开启新旅程」，先设置战场地貌、地图、实际国家数、每国人口上限、起始时代、NPC 难度与迷雾，再选择种族和旗帜，最后从种子地形图的安全编号区域选择出生点。世界种子位于高级选项；种族与旗帜可自由组合。
2. 在底部选择建筑分类和麦田农庄，再点击绿色地块建造。新建筑不会自动招工：选中建筑，在「派遣村民」处点击 **+ / −** 配置工人，让粮食产出覆盖人口消耗。
3. 建造村舍增加住房；粮食充足、幸福度良好时吸引新村民，但仍受开局选择的每国人口上限约束。
4. 用伐木工坊、采石场和集市积攒木材、石料与金币。伐木工坊要靠近森林，采石场要靠近岩地。
5. 建造兵营、箭塔和城墙。给兵营和箭塔安排人员，让经济与防御同步成长。
6. 关注恶龙、龙卷风、丰收、商旅和疫病等随机事件，并观察其他国家的发展。
7. 点击右侧地图图标或按 **M** 打开「诸国」，选择敌国、确认出征人数，再派遣远征军。领主大厅陷落会改变领土归属，统一后可以继续建设。

一个游戏日为 12 秒。顶栏可以暂停，并通过速度按钮在 **1× / 2× / 4×** 之间切换。有人工作的集市可以用金币买卖粮食、木材或石料。保留即时现货贸易，也可以派出需要等待到货的商队订单。

选中本国设施可以升级或修复；受损设施优先修复，完好设施可升级至 3 级。拆除需要再次确认，并返还部分建材；领主大厅不能拆除。

### 科技、外交与管理

按 **R** 或点击右侧书本按钮打开「王国学府与维护」，发展本国的三条研究路线，每条最多 3 级：

| 科技 | 每级效果 |
| --- | --- |
| 农业学 | 粮食总产出 +15%，包括牧场与渔港 |
| 防御学 | 建筑提供的防御 +15% |
| 后勤学 | 训练速度 +10%，远征与商队耗时 −10% |

每个国家同时只能研究一项科技，开始时支付资源，完成后才获得效果。1、2、3 级基础耗时分别为 2、3、4 个游戏日，即 1× 速度下的 24、36、48 秒；晨星教团将这些时长除以 1.2，费用不变。暂停与游戏速度同样影响研究。面板显示当前费用、预计效果与剩余时间，NPC 也会发展自己的科技。

从「诸国」向其他国家提出 **8 日停战**。双方之间须没有在途军队；提议生效时由提出方支付 45 金币。NPC 会直接接受，真人领主需在 3 日内接受或谢绝；接受前不扣金币。停战生效后，双方在 8 日内不能互相出征，期满后自动恢复原有关系。停战不合并国家或改变阵营。

也可以向其他国家 **援助粮食、木材、石料或金币**。援助从自己的库存扣除并送入对方库存；资源不足或对方仓库无法容纳时，整笔援助会被拒绝。

设施面板支持一次派满可用岗位或撤回全部工人，仍受岗位容量和空闲人口限制。批量修复会优先处理大厅与箭塔，再处理其他受损设施；资源不足时修复能够支付的部分，其他国家的设施不受影响。小地图可帮助查看本局各国分布并跳转视角，点击「全图」或按 O 查看整片大陆，按 Home 返回本国。

### 远征军令与召回

按 **G**、从领主手记或诸国面板进入「远征军令」。在「我的远征」查看本国在途部队、士兵数、距出发地比例和剩余时间，点击定位查看行军位置；「可见来袭」只显示当前视野内正向本国进军的敌军，不提供对方军队的召回操作。

本国远征抵达前可以召回。部队会从当前位置沿原路返程，面板显示「归营中」，抵达后士兵重新加入当前所属国家的驻军；不会瞬间传送、向原目标结算进攻或重复归还兵员。归营中的部队继续占外派与训练名额，但不再阻碍停战。暂停、游戏速度、存档和原身份重连都会保留返程进度；联机召回由房主按实际席位验证。

### 出征阵型

确认出征时可选择阵型，并查看预计耗时、攻击与建筑破坏倍率。阵型在出发时锁定；召回、保存和原身份重连都保留原选择。未记录阵型的旧军队按标准军阵处理。

| 阵型 | 行军耗时 | 军队攻击 | 建筑破坏 |
| --- | --- | --- | --- |
| 标准军阵 | ×1 | ×1 | ×1 |
| 疾行突袭 | ×0.75 | ×0.85 | ×0.6 |
| 攻城军阵 | ×1.3 | ×0.9 | ×1.5 |

军队管理显示每支本国部队的阵型；攻城军阵同时展示所属国家族群与时代的攻城器械。按 **G** 后可从「查看攻城机械模型」进入模型图鉴，查看五时代造型。选择阵型不会额外支付资源或改变已选出征人数，士兵仍从本国驻军扣除。

原始覆皮冲车、中古配重投石机、工业蒸汽炮车、现代履带自行榴弹炮与未来开放式悬浮双轨炮各有独立车体；六族饰件和四种阵营风格保留所属身份。三阵型步兵分别呈密集、疏散楔形、两翼护卫中间机械的布局。机械提供场景与行军表现，不另设开火模拟；暂停同时冻结步态与机械，相机仍可移动。

兵营、箭塔和城墙分别拥有原始、中古、工业、现代、未来五时代的独立主轮廓，并保留六族细节与一至三级实体加固外观。士兵装备随时代、族群和四种阵营风格变化；未来设施与士兵使用单独的发光或透明表面，同时保留共享几何和实例合批。返程部队转身朝向出发国，旗标、目标环和小地图同步指向归营方向；连续快照中的返程位置保持单调，不会因旧出征位置倒退或向前跳跃。

### 海空战场

世界设置可选 **大陆诸国、群岛争霸、高原裂谷**，并选择每国 **12–1000 人**的人口上限，默认 1000。上限对所有国家一致，不直接生成居民：实际可容纳人口取住房与所选上限的较小值。联机由房主决定并在大厅展示；旧世界缺少这些设置时按大陆和 1000 人处理。

群岛国家分布在独立岛屿，陆军不能穿水，需要船坞运兵。高原山脊与狭道阻挡陆军，需要绕行；空军可越过山海。特殊战场的陆上远征按可通行陆路行进，找不到路线时拒绝出征。

在紧邻水面的草地建造 **船坞**，派船工持续建造战船；所有时代可造船。**航空场**从工业时代解锁，派工训练飞机。每种军备的训练上限为 24，包含本国在外单位；吞并取得的额外军备会保留，超过上限时暂停生产。军备生产与驻留维护持续消耗资源，可撤工控制开支。

按 **M** 选择敌国，配置战船与载兵跨海登陆，或配置飞机发动空袭；按 **G** 查看库存、阶段与召回。每艘战船可载 4 名士兵，登陆至少 3 人。舰队沿真实连通水路航行，先争夺制海权，再由士兵攻城，胜利可占领国家。飞机从本国航空场直飞目标，敌机与箭塔参与防空；空袭削弱守军和军事设施，不能单独占领领土。

海空行动抵达后进入 3 秒交战窗口，幸存部队自动原路返航。也可主动召回，保持当前位置与原路线；返抵后才归还库存和载兵。路径、交战与归还由房主按真实席位验证，客户端不能指定路线、耗时或战力。暂停、保存和原身份重连保留行动进度。

海军五时代分别使用覆皮桨舟、帆桨战船、铁甲蒸汽舰、现代护卫舰与双体能量舰；空军在工业、现代、未来使用吊舱飞艇、固定翼战机与矢量翼飞行器。船坞与航空场具备阶段主体、六族饰件和等级设备，并加入现有模型图鉴。外国行动遵守私有迷雾。

### 战后医护

实际战斗损失中，进攻方与防守方各有 **40% 转为伤兵**。伤兵暂不参与防守、不消耗驻军日常口粮，仍占兵力名额；召回没有经过战斗的部队不会生成伤兵。国家归附时，伤兵随资产转入胜方，不会被直接删除或变成可用驻军。

完好且有工人工作的 **医馆**自动救治本国伤兵，每位医护乘设施等级每日恢复 **0.5 名士兵**，每实际恢复 1 人消耗 **2 粮食和 1 金币**，按小数精确结算；康复者自动加入驻军。撤回医护、医馆损毁或缺少粮金时暂停，条件恢复后自动继续；驻军达到 10,000 人时需先派出部队。医馆原有移民与疫病效果继续生效。

按 **G** 打开远征军令，可在「战后医护」查看伤兵、医护人数、每日能力和所需资源，直接建造或定位医馆，并派满医护；撤工仍可从设施总览或医馆详情操作。暂停、速度、存档和原身份重连保留实际伤兵与治疗进度，联机派工仍由房主绑定本国席位校验。旧档没有伤兵字段时按零处理。

大厅与村舍拥有五时代的新主体轮廓，包含原始长屋、中古钟楼厅与庭院小屋、工业砖楼与工人住宅、现代市政楼与太阳能住所，以及未来行政核心与生态双舱。六族分别带有独立饰件，二级增加附属楼、三级增加塔柱或门廊；国名牌随实际建筑顶高调整。近景只在本国医馆正在治疗时显示共享实例医疗光点，未派工、缺料、驻军已满或治疗完成后停止，远景隐藏细小光点。

### 工匠工坊与设施总览

按 **B** 或从领主手记进入「城镇设施」，查看本国设施、空缺岗位、受损设施和工匠工坊。总览可以直接派满或撤回工人，也可以定位设施并打开详情；岗位与空闲人口仍按本国实际情况校验。

在「民生」分类建造 **工匠工坊**，费用为 **60 木材、40 石料、35 金币**，初始提供 2 个岗位。有工人的工坊会修复半径 **4 格**内的本国受损设施，包括废墟和工坊自身，优先大厅、箭塔，再按其他设施的编号处理。一级每名工人每日恢复 **12 生命**，每升一级提高 50%；时代与科技不额外加速。每个游戏日为 12 秒。

每实际恢复 1 生命消耗 **0.12 木材与 0.10 石料**，享受所属国家的阵营维修折扣，按小数精确扣费而不向上取整。木石不足时只能完成可支付的部分，补足后自动继续；撤回工人或工坊损毁会停止工作。工坊不会消耗金币修缮或维修他国设施，NPC 也会建设和经营工坊。手动修复及批量修复继续使用原有费用与规则。

礼拜堂、医馆、花园和工匠工坊拥有五时代的独立主轮廓、六族细节及一至三级的实体升级外观。人物新增可辨认的五官、手掌与鞋足细节，强化六族的体型与轮廓，并保留职业工具和时代差异。工坊状态灯跟随实际工作、空闲、未派工、缺料或损毁状态变化，仅显示本国设施状态。上述造型已通过 26 项渲染专项检查，仍使用共享几何与实例合批。

### 牧场与牧畜

在「生产」中建造牧场，消耗 **55 木材、15 石料、20 金币**。一级牧场有 2 个岗位、130 耐久，每名牧工每日基础生产 **6 粮食、2 金币**；每级升级提高 40% 基础产出，并增加 1 个岗位。粮食不随四季变化，不受磨坊或粮仓影响，仍计入本国阵营、种族、农业科技与时代等适用修正。

按 **C** 查看「牧场经营」中的牧场、岗位与精确日产，从这里可建造或定位牧场；也可在建筑详情或 **B** 设施总览派满、撤回工人。无工或损毁时停产，恢复条件后继续。详情中的「近看牧场与牛羊」打开当前等级的三维模型；牲畜是派工与场景表现，不另设购买、繁殖或持有头数的经济规则。

### 渔港与水岸

在「生产」中建造 **渔港**，消耗 **60 木材、25 石料、20 金币**。需要可见的平坦草地，上下左右至少一格紧邻水面；一级提供 2 个岗位、150 耐久。每名渔工每日基础产出 **12 粮食**，春秋正常、夏季 ×1.2、冬季 ×0.75。渔获使用自身季节系数，不享受田作季节、粮仓或磨坊加成，仍计入适用的国家、种族、农业科技与时代修正。

按 **C** 查看渔港数量、岗位、精确粮食日产和接驳收益，可建造或定位本国渔港；派工和撤工沿用设施详情与 **B** 总览。每名在岗渔工乘港口等级提供 1 点接驳，所有完好工作渔港合计最多 **4 点**，每点让新商队耗时减少 **5%**，最多 20%。先计算后勤研究，再乘港口减免；商队出发时锁定实际行程，之后撤工、损毁或拆除不会延长已在途商队。旧商队保留原行程。

渔港详情可进入模型图鉴，查看六族、五时代和一至三级港口与渔船：原始木桩棚、中古木码头、工业砖仓蒸汽设备、现代冷链机动船与未来生态双体船各有独立轮廓；六族饰件、二级卷网设备和三级吊架保留所属身份。每座完好渔港展示一艘船，在岗活动、空岗停泊、损毁隐藏；船只属于场景表现，不新增独立船队经济。渔港沿相邻水面定向，外国船只遵守私有迷雾；暂停保留精确姿态。图鉴选择不改变本局经营状态。

### 四季与民生

每季 8 个游戏日，一年 32 日。田作类粮食春季正常收成，夏季为基础值的 115%，秋季为 130%，冬季为 65%；牧场粮食不受这些季节乘数影响，渔港使用独立的渔获季节系数。人口和驻军口粮不会跟着季节自动降低。按 **C**、点击日期或从菜单进入民政面板，可查看实际粮食产出、口粮、训练消耗与库存预计可维持天数。

**节粮**让村民和驻军的口粮消耗减少 30%，代价是目标幸福度 −12、移民速度 ×0.65；**均衡**保持正常；**宴饮**多消耗 30% 口粮，换取目标幸福度 +10、移民速度 ×1.25。政策不改变士兵训练费用，幸福度会逐渐趋向新的目标。

在「民生」分类建造 **粮仓**并派工，每名工人乘设施等级可在冬季恢复 10 个百分点的田作类粮食产出乘数，多座合计最多恢复 35 个百分点，其余季节不加成，也不提高牧场或渔港粮产。**医馆**每个有效岗位提升 10% 移民速度（最多 40%），减少 20% 疫病损失（最多 80%），损失按整数人数结算且不完全免疫。设施需要保持完好并安排工人。NPC 也会建造这些设施、调配口粮。

### 商路与集市

按 **T**、点击侧栏马车，或从集市设施与菜单进入「商路与集市」。保留原有 **30 单位现货交易**，并可选择粮食、木材或石料，以 **50 / 100 / 200** 单位派出买入或卖出商队。确认时会显示本次总价与预计到货时间；粮价随季节变化，已派出订单锁定价格。联机确认若遇跨季变价，房主会拒绝旧报价，需重新确认。

每座完好且有工人工作的集市提供 **1 个商队名额**，每国发单名额最多 **3 个**，在途与待卸货商队都占用名额。买入出发时支付金币，到达后整批收到资源；卖出出发时扣除货物，到达后整批收到金币。50、100、200 单位的基础行程分别为 **2 / 3 / 4 个游戏日**，每级后勤学减少 10% 行程，再乘以本国渔港接驳减免；暂停与速度同样影响商队进度。

发单前会检查资金、货物、商队名额及已预留的入库容量。若旅途中仓库被其他收入填满，商队会保留整批货物并等待卸货，继续占用名额。国家归附后，其在途商队随国家资产归入胜者；承接的商队超过现有名额时，需等待腾出名额才能再发单。商队进度也保存在存档、联机快照与重连状态中。NPC 会按库存与储备需求进行小额商队贸易。

| 现代 | 24 / 5 | 300 / 260 / 220 / 240 | 60 秒 |

每次只能向下一时代发展，开始时支付本国资源，完成前不提前获得新倍率。时代进阶可与科技研究并行；科技研究速度加成不缩短时代耗时，暂停与游戏速度仍控制进度。进阶项目和剩余时间随存档、世界快照与原席位重连保存。旧世界缺少时代字段时按中古继续。

**NPC 难度**在开局选择：简单降低 NPC 产出与训练速度，决策与出征较慢；标准使用正常速度；困难提高产出与训练速度，建设和军事行动更积极。NPC 也会在满足人口、科技、资源与储备条件后发展时代。难度不是给真人国家增减资源的按钮，也不在对局中切换。

各阵营映射到 **林地木构 / 堡垒石筑 / 海港屋舍 / 圣堂尖顶** 四种风格；大厅、村舍、兵营、箭塔、城墙及士兵装备按归属阵营区分，归附后随新归属呈现。加成由本国阵营与房主规则统一结算，不能在联机指令中指定其他阵营或优惠比例。

### 地图规模、随机地形与战争迷雾

| 地图 | 最大跨度 | 国家数与玩家上限 |
| --- | --- | --- |
| 小型 | 40 格 | 2 |
| 中型 | 48 格 | 2–4 |
| 大型 | 60 格 | 2–6 |
| 巨型 | 72 格 | 2–8 |
| 辽阔 | 144 格 | 2–10 |
| 史诗 | 168 格 | 2–12 |
| 寰宇 | 216 格 | 2–15 |

新地图边界为不规则近圆形，表中的跨度与内部方形存储网格不等于实际可玩面积；旧档保留原有形状。国家数可在地图上限内选择，每个国家最多一位玩家。默认中型四国；未被真人认领的国家由 NPC 发展。大地图包含更多地块与单位，所需显卡和处理器资源也会增加。

新旅程会生成地图种子，也可以手动输入或点击种子旁的按钮换一个。种子决定海岸、河流、湖泊、森林、岩地与对手组合，同样的种子与全部开局选项可重现同一局的开端。各国起始城镇保留可建设区域、附近资源与陆地通道；旧世界继续沿用存档中的地形，不会重新生成。

开局可以选择 **战争迷雾**，默认关闭。开启后，自己的设施与行军中的远征军提供视野，揭开的地形保存在本国探索记录中；离开当前视野后，敌军、设施及城镇人口、防御、库存等动态情报会隐藏。国名与外交关系仍公开，可以向未知国家派遣远征军进行沿路侦察。建造需要处于本国当前视野内，并满足原有领地与地形条件。

联机时由房主决定地图、国家数与迷雾；房间展示全部实际国家的旗帜、种族和人数上限。玩家可在开局前选择空闲席位并修改自己国家的种族，不能改别人或更换房主设置。开局后种族锁定。每国使用自己的探索记录，探索进度随存档、快照与原席位重连保留；视野以连续圆润边界过渡，未探索区与已探索但不可见区域保持区分。普通文件导入、存档与网络快照采用统一的 10 MB 上限。旧存档未记录迷雾时按关闭处理。

### 建筑、村民与士兵造型

大厅、村舍、兵营、箭塔、城墙及士兵装备采用林地木构、堡垒石筑、海港屋舍、圣堂尖顶四类轮廓与装饰。村民提供六种职业造型，搭配不同肤色、衣帽和工具，服饰使用各自阵营配色。所有造型仍由内置几何模型构成，无需下载外部素材。

农庄、伐木工坊、采石场、集市、磨坊与粮仓也有不同的时代主模型。现代能看到拖拉机、锯木生产线、挖掘设备与金属筒仓，未来则使用透明生态温室、能量切割、环形采掘与胶囊仓等轮廓；中古造型继续保留。

### 存档

游玩时约每 30 秒自动保存，切走或关闭窗口时也会尝试保存。进度保存在本机；开始新旅程会替换自动存档。重要进度请从菜单 **导出存档** 为 JSON，之后可通过 **导入存档** 恢复，也可带到另一台设备。

Windows 独立版将存档保存在 **%APPDATA%\DuskRealms** 下。它使用固定的本地内容来源，移动 EXE、重开程序或更新便携版时都沿用此目录；存档不放在每次启动的临时解压目录中。独立版与本地开发页面的自动存档各自独立，可用 JSON 导入 / 导出互相转移。

联机世界由房主自动保存，使用独立于单人进度的存档位置，避免覆盖原来的单人世界。房主离开房间时也会保存，之后可在主界面使用「恢复上次联机快照（单人）」继续。联机期间双方都可导出当前世界快照；离开房间后，可将 JSON 导入单人模式继续。客人不能替房主读取或导入一个新世界。

1.2 版兼容已有 1.0 / 1.1 世界存档，旧世界未研究的科技从 0 级开始。研究进度、停战期限与待回应提议也会随存档和联机快照保存。

1.15 继续读取旧版世界，旧存档没有商队时按空列表处理，没有种族时按人类处理，没有时代时按中古处理，没有战场地貌时按大陆处理，没有人口上限时按 1000 处理，原有地图与阵营编号保留。联机双方需要使用相同的 **1.15.0**，不能与 1.14、1.3 等旧版混用房间。不符合新版地图预设的旧世界仍可单人继续，建立联机房间请创建新版世界。

## P2P 联机

### 与朋友开一局

1. 所有人使用同一版本。房主在主菜单打开「与好友共建世界」，选择创建房间，先设置世界，再选择种族与阵营；点击 **创建联机房间**，填写领主称呼并创建。
2. 房主复制并分享完整的 **dusk-… 房间码**。
3. 好友在主菜单打开「与好友共建世界」，再点击 **加入好友房间**，填写称呼和房间码，连接后选择空闲旗帜，并在「你的国家种族」修改自己的族群。每国一位玩家，按本局国家数最多接纳 2–12 位玩家，满房会拒绝额外加入。
4. 房主点击 **开始这个世界**。未被玩家选择的国家自动发展并参与战争。
5. 每位玩家操作自己的国家；暂停、游戏速度与统一后的继续选项由房主控制。

房主电脑负责运行世界和校验玩家命令。房主请保持程序窗口运行：联机时打开菜单不会暂停全世界。房主关闭程序或离开房间后，当前连接会结束，**没有自动主机迁移**；仍保有快照的玩家可以选择转为单人继续，或导出快照留存。

### 断线与重连

客人断线后，NPC 会接管其国家。开局前可选择空闲国家；开局后不再接纳新领主，只允许原玩家重连。身份凭证保存在 **sessionStorage**，请从原来的浏览器标签页或原来的桌面会话点击 **重连原房间**。关闭整个标签页、清除会话存储或换一台设备后，将无法用新身份认领已开始对局中的国家。

### 信令、NAT 与 TURN

P2P 仍需要建立连接的基础服务。默认使用 **PeerServer Cloud** 交换连接信息，并通过 STUN 尝试让玩家的 WebRTC 数据通道直连；公共信令不运行游戏模拟，也不保存世界。公共服务是否可达取决于网络和服务方状态。官方说明：[PeerServer Cloud](https://peerjs.com/server/cloud)、[PeerJS 常见问题](https://peerjs.com/client/faq)。

某些运营商 NAT、企业防火墙或访客网络无法建立直连。这时双方可以换一个网络，或在联机设置的 **自建信令与中继（高级）** 中填写自己的信令与 ICE 服务。需要 TURN 时，游戏数据会经所配置的 TURN 服务转发；TURN 并非游戏内附赠服务，可能产生带宽费用。

**双方应使用同一个信令地址**，例如 `wss://signal.example.com/peerjs`。该地址需指向兼容 PeerJS 的 PeerServer，可通过 HTTPS / WSS 反向代理部署。网页版在 HTTPS 页面上应使用安全信令；桌面版允许 HTTPS / WSS，另允许本机 localhost / 127.0.0.1 的 HTTP / WS 用于本地测试。

ICE 服务填写标准 JSON 数组，例如：

```json
[
  { "urls": "stun:stun.example.com:3478" },
  {
    "urls": "turns:turn.example.com:5349",
    "username": "你的用户名",
    "credential": "你的短期凭证"
  }
]
```

示例域名和凭证需要替换成自己的可用服务。建议使用短期 TURN 凭证；不要把私人固定凭证写进公开仓库。房间码用于找到房间，不提供账号系统或公共匹配大厅。

## 维护者：本地开发与构建

需要 **Node.js 22 LTS（22.12 或更新版本）**。在项目目录运行：

```sh
npm install
npm run dev
```

终端会显示本地网址。Windows 也可以双击 **启动开发版.cmd**：脚本优先使用系统 npm 或 pnpm，再尝试当前用户的 Codex 内置 pnpm。开发服务器运行期间请保持终端窗口开启。

生成发布版本：

```sh
npm run build
```

构建先做 TypeScript 检查，再生成本地测试目录 **dist/**，最后生成项目根目录的 **暮野诸国.html**。独立 HTML 内联了脚本、样式及运行时许可，Windows 也可双击 **启动游戏.cmd** 打开。它是桌面版打包的内容源；正式分发使用便携 EXE。不要通过双击 dist/index.html 测试，请使用独立 HTML 或运行：

```sh
npm run preview
```

项目同时提交了 pnpm 锁文件，CI 使用 pnpm 11.25.0：

```sh
pnpm install --frozen-lockfile
pnpm run build
```

### 构建 Windows 独立 EXE

在 Windows x64 上安装依赖后运行：

```sh
npm run build:win
```

或使用锁定依赖的 pnpm：

```sh
pnpm install --frozen-lockfile
pnpm run build:win
```

构建会下载官方 Electron 运行时与 electron-builder 打包组件，需要网络。1.25.1 的构建产物为 **release/DuskRealms-1.25.1-Windows-x64.exe**、**release/SHA256SUMS.txt** 和 **release/update.json**；这三个文件组成同一次正式发布。EXE 可以单独运行；校验文件与更新清单供下载核验及程序内更新使用。**release/win-unpacked/** 是用于调试的完整程序目录，里面的 DuskRealms.exe 依赖同目录 DLL 与 resources，不能单独拿走。

本地测试桌面入口可先运行 **npm run build**，再运行 **npm run desktop**。后者通过 Electron 提供的 install-electron 命令准备运行时。仅需程序目录而暂不生成便携包时，可运行 **npm run build:win:dir**。

桌面主进程使用 Electron 的沙箱和上下文隔离，渲染页面不开放 Node.js；游戏从包内读取 HTML，联机时允许信令网络与 WebRTC 数据传输，不启动本地 HTTP 服务，也不打开外部网页。发布构建未配置代码签名证书；若要签名，可在 electron-builder 的发布环境中配置自己的证书。

更新源固定在 **desktop/update-source.json**；构建时 **scripts/prepare-desktop.mjs** 可从 CI 的 **GITHUB_REPOSITORY** 填入同一仓库。更新请求由主进程执行，preload 提供检查、下载、读取状态与打开已校验下载位置四个无参数方法；1.16 另提供窗口状态查询、受限模式 / 预设设置与可取消的状态订阅。所有请求均校验主窗口与主 frame 的固定来源；页面不能指定网络地址、目标路径或执行程序，窗口请求也不接受任意尺寸或原生命令。窗口偏好单独写入 **window-settings.json**。测试可以用 **DUSK_REALMS_DATA_DIR** 指定独立数据目录，正常发布版仍使用上述固定的用户存档目录。

官方参考：[Electron 应用分发](https://www.electronjs.org/docs/latest/tutorial/distribution-overview)、[electron-builder Windows portable](https://www.electron.build/docs/api/app-builder-lib.interface.portableoptions/)。

## 技术与项目结构

基于 **Game Studio 工作流、TypeScript、Vite 和 Three.js**。建筑、地形、村民与环境采用项目内的程序化几何建模，不依赖付费素材服务。经营模拟与渲染分离，适合继续加入新建筑、阵营和事件。

```text
src/                      游戏逻辑、3D 场景与界面
scripts/standalone.mjs    将构建结果内联为独立 HTML
desktop/                  Electron 主进程、沙箱 preload、更新器与图标
.github/workflows/        Windows 构建与版本标签发行（本地保留）
release/                  Windows 程序输出（不提交源码仓库）
暮野诸国.html             构建生成的可直接游玩文件
启动游戏.cmd              Windows 独立版入口
启动开发版.cmd            Windows 开发服务器入口
```

本地 1.25 支持单人离线与按地图容纳 2–15 人的 P2P 房间。不包含账号服务器、公共匹配大厅、主机迁移或跨设备云存档。玩家从 GitHub Release 下载 EXE 后可以各自单人游玩，也可以互发房间码进入同一个世界。
